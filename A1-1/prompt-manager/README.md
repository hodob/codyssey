# 나만의 프롬프트 관리 프로그램

흩어진 생성형 AI 프롬프트를 한곳에서 등록하고 검색하는 Python 콘솔 프로그램입니다. 상단 제목, 중앙 내용, 하단 선택 메뉴로 구분된 페이지형 화면을 제공하며 프롬프트의 제목, 내용, 카테고리, 즐겨찾기 여부를 관리합니다. 화면은 페이지를 출력할 때마다 현재 터미널의 폭과 높이를 확인해 자동으로 조정됩니다. 보너스 1의 JSON 영구 저장과 카테고리별 Markdown 내보내기도 지원합니다.

## 개발 환경

- Python 3.10 이상(개발 및 검증: Python 3.14.6)
- Git(개발 및 검증: Git 2.55.0.windows.3)
- 외부 Python 라이브러리 사용 안 함

## 실행 방법

1. 저장소를 내려받습니다.

   ```bash
   git clone https://github.com/hodob/A1-1-prompt-manager.git
   cd A1-1-prompt-manager
   ```

2. 프로그램을 실행합니다.

   ```bash
   python prompt_manager.py
   ```

3. 메인 페이지 하단의 번호를 입력해 원하는 기능을 사용합니다. 목록이 여러 페이지이면 `P`와 `N`으로 이전·다음 페이지를 이동하고 `0`으로 메인 페이지에 돌아갑니다. 일반 결과 페이지에서는 `Enter`를 누르면 메인 페이지로 돌아가며, 메인 페이지에서 `0`을 입력하면 종료됩니다.

## 기능

1. 프롬프트 추가
2. 전체 프롬프트 목록 보기
3. 카테고리별 조회
4. 제목 또는 내용 키워드 검색
5. 프롬프트 상세 보기
6. 즐겨찾기 추가 및 해제
7. 즐겨찾기 목록 보기
8. 카테고리별 Markdown 파일 내보내기
9. JSON 자동 저장 및 시작 시 불러오기(보너스 1)
10. 빈 입력, 잘못된 메뉴와 프롬프트 번호 검증
11. 최대 폭 제한 없이 터미널 너비에 따라 줄바꿈과 메뉴 행이 달라지는 반응형 화면
12. 터미널 높이에 따라 목록 수를 조정하고 선택 메뉴를 마지막 행에 배치
13. 목록 페이지의 이전·다음·메인 페이지 이동
14. 제목·내용·카테고리를 독립 페이지에서 입력하는 3단계 추가 화면

## 데이터와 카테고리

프롬프트는 리스트 안의 딕셔너리로 관리합니다.

```python
{
    "title": "프롬프트 제목",
    "content": "프롬프트 전체 내용",
    "category": "이미지 생성",
    "favorite": False
}
```

기본 카테고리는 다음과 같습니다.

- 텍스트 생성
- 이미지 생성
- 영상 생성
- 페르소나
- 자동화
- 기타

사용자는 프롬프트를 추가할 때 새로운 카테고리를 직접 입력할 수도 있습니다.

## 보너스 1

- 프로그램 시작 시 `prompts.json`을 UTF-8로 읽습니다.
- 프롬프트 추가와 즐겨찾기 변경 시 JSON에 자동 저장합니다.
- JSON이 처음부터 없으면 기본 프롬프트 3개로 새 파일을 생성합니다.
- 메뉴 8번을 실행하면 `exports` 폴더에 카테고리별 Markdown 파일을 생성합니다.

## 파일 구조

```text
prompt-manager/
├── prompt_manager.py       # 프로그램 소스코드
├── prompts.json            # 영구 저장 데이터
├── exports/                # Markdown 내보내기 결과
├── tools/                  # 실행 증빙 재현 도구
├── README.md
└── .gitignore
```
